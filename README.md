# Plants_Vs_Zombies_Python_Game

## Project Overview
This project is a **Plants vs Zombies–inspired tower defense game** developed in **Python** using **Tkinter/Pygame**.  

The game allows players to strategically place plants to defend against waves of zombies. It demonstrates **game development concepts**, including GUI design, event handling, animations, and object-oriented programming.  

The goal of this project is to **apply programming logic in an interactive environment** and build a complete desktop game showcasing real-time user interaction.


---

## Workflow
1. **Game Design** – Planned gameplay mechanics inspired by Plants vs Zombies.  
2. **GUI Development** – Built interface using Tkinter/Pygame.  
3. **Game Logic Implementation** – Implemented plant placement, zombie movement, and attack system.  
4. **Object-Oriented Design** – Created classes for plants, zombies, and game management.  
5. **Event Handling** – Managed user input (mouse clicks, actions).  
6. **Animations & Updates** – Added real-time updates and visual elements.  
7. **Testing & Debugging** – Ensured smooth gameplay and fixed bugs.  

---

## Features
- Strategic tower defense gameplay  
- Multiple plants with unique abilities  
- Zombie enemies with movement and attack mechanics  
- Interactive graphical user interface  
- Real-time animations and updates  
- Modular and structured code design
